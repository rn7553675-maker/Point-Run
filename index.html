About Point Run

Free · Browser-based · No download needed

Point Run is a free 3D endless runner built with Three.js. Race as an adorable penguin through a frozen arctic world — shoot enemies, dodge bosses, collect coins, and chase the highest score possible.

Mission Our Goal

Built for players who want a fun, fast, accessible experience — no sign-ups, no paywalls. Open the link and play instantly on any device.

Tech Technology Stack

  • Three.js — immersive real-time 3D graphics
  • Web Audio API — procedural sound effects
  • HTML5 / CSS3 / JS — runs in any modern browser
  • localStorage — persistent high score, no server needed

Dev Developer

Point Run is an independently developed passion project. If you enjoy the game, share it with friends and challenge them to beat your score!

Contact Get in Touch

Found a bug or have suggestions? Reach out via the game's official page — your feedback helps us improve!

Tips for High Score

Pro strategies to dominate the leaderboard

Ammo Ammo Management

  • Don't waste shots on enemies you can dodge — save ammo for bosses
  • Bosses need multiple hits; regular monsters die in one shot
  • Always collect cyan energy orbs to refill ammo mid-run

Lanes Lane Strategy

  • Stay center lane when possible — fastest reaction left or right
  • Switch lanes early — never wait until the last second
  • When a boss appears, position to shoot while staying off-center

Point Run – Free Online 3D Endless Runner Game

Point Run is a free online 3D endless runner game where you control a cute penguin character and try to survive as long as possible. Run forward, avoid dangerous obstacles, shoot enemies, collect coins, and beat your high score — all in your browser with no download required!

🎮 How to Play Point Run

Playing Point Run is simple and fun. Follow these steps to get started:

  • 👉 Move Left / Right: Swipe on mobile or use Arrow Keys / A-D on keyboard
  • 👆 Jump: Tap the screen or press the Up Arrow / W key
  • 🔫 Shoot: Tap the shoot button or press Space Bar to fire at enemies
  • 💰 Collect Coins: Run over coins to increase your score
  • ⚡ Survive: The game gets faster over time — stay focused!

🌟 Game Features

  • ✅ Full 3D graphics powered by Three.js
  • ✅ Endless runner gameplay with increasing speed
  • ✅ Shooting system with ammo management
  • ✅ Boss enemies with unique abilities (IceKing, FireGiant, ThunderLord and more!)
  • ✅ High Score system saved in your browser
  • ✅ Works on mobile and desktop — no download needed
  • ✅ Completely free to play

🏆 Tips to Get a High Score

  • 🎯 Save ammo for boss enemies — they need multiple hits
  • 🏃 Stay in the center lane when possible to react faster
  • 💡 Shoot regular enemies for +50 points each
  • 👑 Defeating bosses gives massive bonus points (200–1000!)
  • 🔄 Play again after each run — the more you play, the better you get

📱 Play on Any Device

Point Run is fully optimized for both mobile phones and desktop browsers. Whether you are on Android, iPhone, or PC, you can enjoy a smooth and immersive gaming experience. Just open the game in your browser and start playing instantly — no installation required.
